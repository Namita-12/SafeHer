# 🚨 SafeHer

SafeHer is a Women Safety Emergency Web App built using HTML, CSS, JavaScript, Firebase, and PWA technology.

## ✨ Features

- 🚨 SOS Emergency Button
- 🔊 Emergency Siren
- 📍 Live Location Sharing
- 🗺 Google Maps Integration
- 🔥 Firebase Emergency Logging
- 🎤 Voice SOS Detection
- 📳 Shake Detection
- 📷 Emergency Camera Access
- 📞 Emergency Contacts
- 📩 Emergency SMS
- 🌦 Live Weather
- 🕒 Live Clock
- 📱 Installable PWA App

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Firestore
- Web APIs
- Progressive Web App (PWA)

## 📱 Installation

1. Open the deployed SafeHer link
2. Tap "Install App" or "Add to Home Screen"
3. Use SafeHer like a native mobile app
