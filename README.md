# 🚨 SafeHer

> Your emergency safety companion.

A modern women safety web app with SOS alerts, live location sharing, voice activation, shake detection, emergency SMS, and Firebase logging.

## ⚡ Features

- 🚨 One-Tap SOS
- 📍 Live Location Tracking
- 🎤 Voice SOS Detection
- 📳 Shake Detection
- 📷 Emergency Camera
- 📩 Emergency SMS
- 🔥 Firebase Logging
- 🌦 Live Weather
- 🕒 Real-Time Clock

## 🛠 Built With

- HTML
- CSS
- JavaScript
- Firebase
- Google Maps API
- PWA Technology

---

## 🚀 How It Works

1. Open SafeHer
2. Trigger SOS manually, by voice, or by shaking phone
3. Live location activates
4. Emergency data gets logged
5. SMS alert can be sent instantly
